Desktop stereo-3D viewers · competitive field

The lane is open.

StereoPhoto Maker owns mindshare. Nobody found in the field owns the standards-based path from a desktop photo viewer to an eye-tracked lenticular display.

Strategic verdict Sprint at Acer SpatialLabs via OpenXR.

It is the only glasses-free family in this study with a certified OpenXR runtime, and PixelSpy’s pyopenxr advantage makes the route unusually direct.

Where users
feel the seams.

The loudest problems are less about stereo math than friction: old UI, platform limits, brittle graphics paths, invisible modes, and output that quietly changes the image.

STEREOPHOTO MAKERHIGH · diffuse evidence

Dated, hard-to-learn interface

A decade-long review consensus describes a Win95-era, jargon-heavy menu tree. The official changelog says the batch menu moved because File had become too large; an illustrated-guide ecosystem fills the teaching gap.

BEST FIT · OPENXR

Acer SpatialLabs

Eye-tracked two-view lenticular. SpatialLabs Pro devices are OpenXR-conformant; Acer also offers a SteamVR Bridge and engine plugins.

MULTIVIEW · 45–100 VIEWS

Looking Glass

HoloPlay plus quilt format. A stereo pair needs 2→many view synthesis; no researched viewer attempts it.

WATCH ITEM · NO PUBLIC SDK

Samsung Odyssey 3D

27″ 4K 165 Hz G90XF launched Mar 2025 with eye tracking and 3D Hub. No public developer path was found.

NOT A DESKTOP PATH

Active, but Android/mobile. Dimenco is B2B/OEM; Alioscopy and ProMa are signage-oriented.

Recommendation

Sprint narrowly. Preserve the general architecture.

01

Ship the clean two-view pipeline first

Keep view dissection separate from final multiplexing. That supports anaglyph now without committing to a vendor-specific output layer.

02

Add an OpenXR presentation path

On the evidence found, the same desktop path can target SpatialLabs Pro and VR HMDs—two photo-viewer sub-niches with no identified incumbent.

03

Make display behavior ordinary

Use standard fullscreen behavior, expose modes in the UI, preserve source pixels, and keep the cross-platform advantage. Those choices directly answer the loudest competitor failures.

04

Defer true multiview synthesis

Looking Glass is architecturally compatible with pass-per-view, but driving 45–100 views from a stereo pair is a different problem from presenting two eyes.

Risk to monitor: Samsung could change the map by publishing an SDK. Today’s evidence shows hardware and title partnerships, but no open developer story.

How to read the evidence

  • Verified live means the page, source, API, or manual text was actually read on 3 Oct 2026.
  • Index means only search-index content was available; it is weaker and labeled where it matters.
  • Comment and participant counts are approximate and include maintainers. Many threads are reporter–maintainer exchanges, not crowds.
  • Commercial-product grievance evidence is thin. Those rankings are the loudest whispers, not broad sentiment measurements.
